# 🎧 Spotify UI Clone

A responsive front-end clone of the **Spotify** web player interface built using **HTML** and **CSS**. This project focuses on replicating the design and layout of Spotify's sleek music player experience.

## 🛠️ Tech Stack

- **HTML5** – Structure of the webpage
- **CSS3** – Styling and layout
